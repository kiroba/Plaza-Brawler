# Plaza Brawler 2D Fighter (LPE MMORPG Test Run)

Decentralized 2D Fighter mini-game built for **The Omniverse** game layer (`kiroba/Phaser-Studio/games/plaza-brawler`).

## Run locally

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Open the URL printed by Vite (by default, `http://127.0.0.1:3000`). Do not open `index.html` directly as a `file://` URL; the browser needs the local server to load the game modules and assets.

## Features
- **User LPE vs OmniMind LPE**: Player character dynamically pulls the end-user's Live Persona Engine (LPE) avatar from the local daemon (`:5000`/`:5002`), while the opponent is generated by OmniMind using Zodiac astrological parameters.
- **Complete Scene State Flow**: Splash Screen -> Boot -> Preload -> Main Menu -> Settings -> Fighter Scene -> Win/Lose Game Over Screen.
- **Decentralized IPC Hooks**: Action events (attacks, damage, win/loss) are Ed25519-signed and dispatched to the local Omni Node loopback daemon.
- **Zero-Cost Hosting**: Runs standalone in browser/WebView and deploys via GitHub Pages ($0 server costs).
